---

## 2. Key Architecture & Features

1. **4D Temporal Reconstruction:** Reconstructs historical monuments across different historical eras using photogrammetry, point cloud synthesis, and neural radiance fields.
2. **Epigraphy Restoration Engine:** Utilizes machine learning to restore damaged stone inscriptions, transliterating ancient Brahmi/Devanagari scripts and providing historical context.
3. **Interactive 3D Web Viewer:** Fluid WebGL viewer allowing virtual tourists and archaeologists to inspect architectural relics at sub-millimeter precision.
